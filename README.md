# 墨算 VideoFlow

跨平台录播课程文件与封面管理工具。支持 Windows、macOS、本地文件夹、系统挂载的 SMB/NAS；未来对接 fanlaoshishu.com。

## 核心工作流

录制视频命名为 `P012.mp4` → 选择教材/课程 → 导入 Excel/CSV 目录 → 按页码和题号匹配 → 预览批量改名结果 → 用户确认后执行 → 关联封面和归档。

## 性能约束

- 默认文件列表为纯文本，不自动播放、解码视频或生成缩略图。
- 扫描只读取必要的文件名和文件属性，不调用 ffprobe/FFmpeg，不计算全文件哈希。
- 仅用户点击“预览”或“详细信息”时加载对应媒体。
- SQLite 分页查询；前端虚拟列表；扫描、文件操作在 Rust 后台任务执行。
- NAS 扫描采用限流、超时、增量处理；断线不得误判为文件被删除。
- 批量重命名不转码；所有文件修改先预览、检查冲突，记录可撤销日志。

## 技术栈

- Tauri 2 + Rust
- Vue 3 + TypeScript + Vite
- SQLite（WAL、迁移、索引）
- FFmpeg/ffprobe（仅按需调用）
- GitHub Actions（Windows/macOS 构建）

## 命名规则

默认模板：`{页码}_{题号}_{名称}.{扩展名}`。

- `P12`、`p012` 标准化为 `P012`。
- 课程上下文必须明确；相同页码可能属于不同教材。
- 同页多题且缺少题号时标记为待确认，不猜测。
- 文件名非法字符、大小写冲突、已有目标文件必须在预览时拦截。
- 目录是命名依据，不从视频内容猜测题名。
