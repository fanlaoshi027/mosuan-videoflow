# 开发状态（V0.1）

## 已提交代码
- Vue 3 + TypeScript 界面，CSV 文本编辑与 UTF-8 CSV 文件读取
- 课程目录 SQLite 持久化（按课程整体替换）
- Rust 只读单层视频文件夹扫描（文件名、路径、大小）
- 页码/题号匹配及只读重命名预览（目录预索引，批量匹配）
- 重命名预览每页 100 条，避免一次渲染全部表格行
- SQLite 目录重新载入时正确转义 CSV 特殊字符
- Tauri 2 最小桌面骨架
- Windows/macOS GitHub Actions CI，构建前生成平台图标
- 基础命名引擎单元测试

## 已知限制
- 未验证 CI 实际构建结果；不应声称已有可安装软件
- CSV 解析当前使用简单逗号分割，不支持带引号/逗号/换行的复杂单元格
- XLSX 导入尚未实现
- SQLite 目录当前按课程整体替换，不提供编辑历史
- 扫描为单层目录；NAS 超时、取消、增量索引尚未实现
- 前端预览表格已加入 100 条分页，但尚未实现虚拟滚动和 SQLite 文件分页；大量记录性能尚未验证
- 仅预览命名，不进行任何磁盘修改
- 未实现封面、媒体预览、网站对接
